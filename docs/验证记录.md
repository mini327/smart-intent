## 方案实现差异

- 使用官方 SDK 低层 Server 注册严格且扁平的工具 schema，以便准确控制参数及结果；领域逻辑不依赖 SDK。
- 首版 JSONL 对七个映射字段均做严格检查，时间字段必须带偏移；未实现无偏移源时区推断。
- 为控制维护成本，模块按领域拆分为少量文件，保留将来扩展为目录的空间。
- 默认内存上下文；持久模式仅支持 schema 1，遇到未知版本拒绝启动，未承诺自动跨版本迁移。
- 不自动重试失败操作；返回 retryable 与具体错误，由调用方按范围决定，避免隐藏重复操作。
