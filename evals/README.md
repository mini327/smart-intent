# 宿主效果评测

自动化测试验证服务行为，不能代替模型在实际宿主中的任务完成评估。本目录记录基线实验方法，尚无真实宿主效果结论。

## 执行方法

准备至少30条固定任务，分别覆盖明确请求、关键歧义、连续追问、时间筛选、数据缺失和工具异常，每类至少5条。每个任务在 Skill 单独运行与 Skill 加插件两组中各执行3次，保持同一模型、数据快照、可访问工具、权限及起始状态。

两组必须都能访问同一测试数据，避免把新增数据访问权限误当作上下文理解收益。示例数据只用于测试；真实授权数据的脱敏与存储另行管理，不提交仓库。

## 记录字段

每次记录 case_id、group、run、host_version、model、data_sha256、expected_target、expected_scope、observed_result、success、unnecessary_questions、tool_calls、elapsed_ms、tokens、evidence、failure_reason。

当对象、动作、范围或结果依据任一关键项错误时，success=false。用户明确要求修改而模型只给建议也属于未完成。无效追问指答案已在可用上下文中且不涉及关键歧义的重复问题；必要权限确认不计入。

## 发布门槛

隔离、越界拒绝和无虚假成功声明等关键用例必须全部通过；总体成功率不低于基线；无效追问相对下降20%，若基线为零则保持为零。记录样本量和每类失败，不凭小样本宣称统计显著。
